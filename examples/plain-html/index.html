Kaal Jyoti widgets

One script tag — a small loader that fetches each element's code the first time the page has one — twenty-two elements, staging API. This page is also the manual QA page; each widget has an anchor (#kj-dasha, #panchang, …).

1 · Panchang

The same day in both languages; each card is one call.

2 · Muhurta

The choghadiya and the windows: its own call (/v1/panchang/muhurta), not shared with the Delhi panchang above.

3 · Themed

3a · Presets

preset (or data-preset on the script): the four looks of the PDF reports — classic (the default), modern, minimal, traditional. The theme still decides light, dark or auto.

4 · Chart and the kundli report

The chart has its own North / South / Circular switch. The form's place is one search box; the report under it has tabs (Overview, Charts, Planets, Dasha, Life areas and, with readings, Readings), each loaded the first time it is opened. The last entry is remembered on this device (remember="off" to stop that).

4a · Place search: Photon, Google or Kaal Jyoti

Type a village into the place box. Without a Google Maps key the first form searches Photon (OpenStreetMap, free, no key; the list credits OpenStreetMap), and falls back to Kaal Jyoti's own index if Photon fails or takes over 4 seconds. Open this page as /?gmaps=AIza… with a key of yours (Places API (New) and Maps JavaScript API enabled, referrer http://localhost:3000/*) to search Google Places instead. A Photon or Google pick sends no timezone, so the API derives it. No key is committed here.

place-provider="kaaljyoti": only Kaal Jyoti's own index (towns of 1,000+ people, one call per search), for a site that wants no third-party call.

5 · Ashtakoot

Two birth forms and the guna milan between them: three calls per submit (the match and one kundli per person), none for an identical resubmit.

5a · Horoscope and readings

A sign picker and period tabs (one call per sign, period and day) drawing a summary and five life areas with a level each, and a lagna and a nakshatra reading — one preset, one from a picker. Every answer ends with the disclaimer line; the nakshatra one names an astrologer.

5b · Personal readings

One birth (14 May 1990, 10:30, New Delhi), one call per report at 5 credits each — and one kundli report of three parts, priced as three (15 credits). On every plan; a key that has used up its month's credits says so in each one's place.

8 · Monthly panchang

/v1/panchang/month is a heavy route (20 credits, ten a minute): the widget calls it with the publishable key, or through the site's proxy (data-proxy on the script, or proxy here) when there is one, which can cache the month.

9 · Hindu calendar converter

A date to Vikram Samvat, masa (both reckonings), paksha and tithi: 2 calls.

10 · Planets today

A chart of this minute and a table: 2 calls.

11 · Ephemeris

Heavy like the monthly panchang: 20 credits a month shown.

12 · Moon sign and nakshatra

The compact birth form: after a submit it folds into one line with "Edit details". The entry is remembered for every calculator on the device.

13 · Lagna

The birth given as attributes: no form, the result at once.
